Blinkit Data Analysis Using Power BI

This project is based on analyzing Blinkit (India’s last minute delivery app) dataset using Power BI. The main objective of this project is to understand sales performance, customer behavior, and outlet performance using different visualizations.

First, I imported the dataset (Excel file) into Power BI and performed data cleaning. I checked for missing values, corrected data types, and created necessary columns for better analysis. After that, I created relationships between tables and used DAX functions to calculate important measures like Total Sales, Average Sales, Average Rating, and Number of Items.

In the dashboard, I have created multiple KPIs such as Total Sales ($1.20M), Average Sales ($141), Average Rating (3.9), and Number of Items (8523). These KPIs give a quick overview of business performance.

I also added a filter panel where users can filter data based on Outlet Location Type, Outlet Size, and Item Type. This makes the dashboard interactive and easy to use.

To understand sales distribution, I created charts like:

* Fat Content Analysis (Low Fat vs Regular)
* Item Type wise sales (Fruits, Snacks, Household, etc.)
* Outlet Size distribution (Small, Medium, High)
* Outlet Location (Tier 1, Tier 2, Tier 3)

I also included a line chart showing Outlet Establishment over the years to analyze trends. Additionally, a table is created to compare Outlet Types such as Grocery Store and Supermarkets with metrics like Total Sales, Number of Items, Average Sales, Rating, and Item Visibility.

From the dashboard, we can see that Tier 3 outlets and Supermarket Type1 contribute the highest sales. Also, regular fat products have slightly higher sales compared to low fat products.

Overall, this project helped me understand how to use Power BI for real-world business analysis. I learned data cleaning, data modeling, DAX calculations, and creating interactive dashboards. This project can help businesses make better decisions based on data insights.
